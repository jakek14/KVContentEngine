## Post

51% of all code on GitHub is now AI-assisted.

That stat keeps getting quoted as a productivity number. I think it's actually a founder leverage number.

Here's what I mean.

For most of my career, building meant two things: you could code and you built it yourself, or you had an idea and paid someone to build it for you. The gap between "I think this should work differently" and "let's test it" was enormous -- weeks, sprints, negotiation.

AI coding tools are closing that gap in a way I didn't see coming.

Not because I write better code faster. But because I can hold a product decision in my head and execute it the same afternoon.

That changes the math on bootstrapping.

Before, every product decision was a negotiation with a roadmap. Now it's just a question of: is this actually the right call? Because if it is, we can move.

The best tools right now -- Cursor, Claude Code, the others -- aren't magic. They're multipliers. They amplify whatever clarity you bring. A vague prompt gets a vague result. A sharp, specific brief gets something you can ship.

The founders winning with this aren't the ones who learned to prompt faster. They're the ones who got better at deciding what to build.

That's the real shift. The execution ceiling is higher. So thinking quality matters more, not less.

If you're a founder using these tools, the leverage isn't in the code. It's in the clarity you bring before you type a single prompt.
