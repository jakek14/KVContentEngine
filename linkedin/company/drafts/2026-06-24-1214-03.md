## Post

Shopify Scripts stops running on June 30.

That's 6 days from now.

If you're running checkout customizations -- tiered discounts, bundle pricing, custom shipping rules, gift card logic -- and they're built on Shopify's legacy Scripts system, they stop working Tuesday.

This isn't a "plan to migrate soon" situation.

The replacement is Shopify Functions. It's the modern, supported version with the same capabilities. Shopify's migration documentation is thorough and covers most checkout-specific scenarios.

Many agencies are fielding last-minute migration requests right now from merchants who assumed someone else had handled it. A lot of those conversations are happening this week in a panic.

If you run a Shopify store: go to Admin > Settings > Checkout today and confirm whether you have active Scripts. If yes, get your development team on it immediately -- not Friday, today.

The deadline has been public for months. But most brands only see it in the last week.

If someone on your team needs to see this today, send it their way.
