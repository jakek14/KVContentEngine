## Post

$850 billion in US retail returns last year.

The average ecommerce return rate is 19.3%.

Every return is a CAC you already paid that produced zero net revenue. The ad spend, the shipping, the fulfillment -- it all happens twice when a customer buys and sends it back.

Most D2C brands treat returns as a logistics problem. But a 19% return rate isn't a logistics problem. It's a margin problem wearing logistics clothes.

What actually moves the number: better product imagery (most returns happen because the item "wasn't as expected"), sizing tools that work, and review content that sets accurate expectations instead of overpromising.

The cheapest customer is the one who buys and keeps it. That starts long before they hit checkout.

Save this if you're working on reducing return rates.
