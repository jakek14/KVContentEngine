## Post

The vibe coding productivity paradox nobody talks about:

GitHub says AI tools deliver a 55.8% speedup.

A randomized controlled trial of experienced developers found they were 19% slower.

Both are true. That's what makes this interesting.

Experienced engineers fight the AI's suggestions. They debug generated code, correct assumptions the model made about their existing architecture. The friction is real.

But 63% of people using vibe coding tools right now aren't developers.

Founders. Product managers. Marketers. Designers.

For them, the baseline comparison isn't "how fast would I code this myself."

The baseline is "I couldn't build this at all."

That's the actual shift. Not that developers are faster. But that the gate labeled "first you need to hire an engineer" just got a lot smaller.

## Context

The vibe coding statistics for 2026 reveal an interesting tension -- experienced devs may not be faster, but the addressable market for AI coding tools is primarily non-developers (63%). For a founder, the real unlock is that the barrier to building a prototype or internal tool has dropped dramatically, not that developer productivity improved.
