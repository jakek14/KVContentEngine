## Post

95% of YC's latest batch shipped code that was mostly written by AI.

That number gets read as: "anyone can build now."

What it actually means is more interesting.

The speed of execution was never the moat. It was always an input cost. The founders who could code quickly always could — and most of them still shipped things nobody wanted.

What AI did: it commoditized execution. Not judgment.

You can now ship a broken idea faster than ever. You can polish something nobody wants to a higher standard than before. You can validate nothing and still have something that looks like progress.

The best builders I've seen using AI aren't impressed by the velocity. They're more ruthless about what they're building because they know the cost to ship went to zero — which means the only expensive thing left is being wrong about what to build.

Execution is now table stakes.

The bottleneck moved. Clarity about what to build, for whom, and whether they'll pay for it — that's the actual work now.

That was always true. AI just made it impossible to hide behind the other stuff.

## Context

Y Combinator reports their latest batch is ~95% AI-generated code — the clearest signal yet that vibe coding has moved from trend to default. The counterintuitive take: this isn't a democratization story, it's a clarification story. Execution was never the scarce resource. Judgment about what to build always was. AI just stripped away the last excuse founders had for not confronting that directly.
